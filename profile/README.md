# DevSoft-LK

### Building useful software, openly.

**DevSoft-LK** is a software development and open-source organization from [Sri Lanka](https://maps.app.goo.gl/hc3N6kGjeR3YVEUK7), focused on building practical applications, developer tools, reusable components, and accessible learning resources.

We believe software should solve real problems, encourage collaboration, and help developers learn by building.

## What We Do

- **Open Source Development** — Build and maintain useful software projects.
- **Web Development** — Explore modern technologies and practical application development.
- **Community Collaboration** — Share knowledge, exchange ideas, and welcome contributions.

## Featured Projects

| Project | Description |
|---|---|
| [Folder Organizer](https://github.com/DevSoft-LK/folder-organizer) | A React Desktop App that organizes files into folders by file type. |
| [Community](https://github.com/DevSoft-LK/community) | The central space for announcements, questions, suggestions, and discussions. |

## Get Involved

We welcome developers, learners, and open-source enthusiasts who want to learn, contribute, and build useful software.

- Browse our [public repositories](https://github.com/orgs/DevSoft-LK/repositories).
- Join our [community discussions](https://github.com/DevSoft-LK/community/discussions).
- Explore a project, report an issue, or suggest an improvement.
- Contribute through pull requests and constructive feedback.

Please follow each project's contribution guidelines before submitting changes.

## Our Principle

> Build practical solutions. Share knowledge. Learn together. Contribute openly.
